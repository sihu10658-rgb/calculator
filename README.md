# 별난 계산기 (Crazy Calculator)

`plan.md` 개발계획서대로 만든 **순수 HTML + CSS + Vanilla JS** 웹 공학용 계산기.
외부 라이브러리·빌드 도구 없음. `index.html`을 브라우저로 열면 바로 실행됩니다.

```
index.html   # UI 구조
style.css    # 이상한 UI 스타일 & 애니메이션
script.js    # 수학 엔진 + 그래프 + 트롤링 제어
```

## 빠른 시작

```bash
open index.html          # macOS
# 또는 로컬 서버로
python3 -m http.server 8000   # → http://localhost:8000
```

## 입력 예시

```
3+4*2            →  11
2^10             →  1024
5!               →  120
ln(e) + log(1000) →  4
log(8, 2)        →  3        (밑이 2인 로그)
2pi              →  6.28318530718   (암묵적 곱셈)
rand(1, 100)     →  범위 안의 난수
isprime(97)      →  1        (소수면 1)
primepi(1000)    →  168      (1000 이하 소수의 개수)
zeta(2)          →  1.64493406685   ( = π²/6 )
zeta(-1)         →  -0.0833333333333 ( = -1/12 )
```

그래프 칸에는 `x`를 쓴 식을 넣습니다. `sin(x); x^2/10; zeta(x)` 처럼
세미콜론으로 나누면 여러 개를 한 번에 그립니다.

## 기능

| 요구사항 | 구현 |
|---|---|
| 사칙연산 | `+ - * / %`, 괄호, 우결합 `^`, 단항 부호, 암묵적 곱셈(`2pi`, `3(4+1)`) |
| 로그 연산 | `ln(x)`, `log(x)`(상용), `log(x, b)`(밑 지정), `log2`, `log10` |
| 지수 함수 | `x^y`, `exp(x)`, `pow(a,b)`, `sqrt`, `cbrt` |
| 랜덤 함수 | `rand()`, `rand(a,b)`, `randint(a,b)` + 범위 지정 UI |
| 소수 계량 | `isprime(n)`(밀러-라빈), `primepi(x)` = π(x)(에라토스테네스 체 캐시), `nextprime`, `prime(k)`, 소인수분해 |
| 제타 함수 | `zeta(s)` — Euler–Maclaurin 전개, `s < 1/2`는 함수방정식으로 해석적 연속 (ζ(2)=π²/6, ζ(-1)=-1/12 확인) |
| 그래프 | HTML5 Canvas 2D. 세미콜론으로 여러 식 동시 렌더, 드래그 이동 / 휠 확대축소, 점근선 자동 끊기 |

그 밖에 삼각·쌍곡 함수, `gamma`, `fact`/`!`, `gcd`, `lcm`, `min`, `max`, `floor`, `ceil`,
상수 `pi(π)`, `e`, `tau`, `phi` 지원. 계산 기록은 클릭하면 다시 불러옵니다.

## 이상한 유저 인터페이스 (Weird UI)

- 뒤죽박죽 섞이는 키패드 배치, 버튼마다 제각각인 폰트 크기와 회전
- 누를 때마다 살짝 도망가는 버튼, 마우스를 피하는 `=` 버튼(3번 피하면 항복)
- 찌그러진 입력창, 글자마다 뒤틀린 결과 표시, 랜덤 사운드, 방해 팝업

**기괴함 레벨 슬라이더(0~3)** 로 강도를 조절합니다. `0`은 완전히 멀쩡한 계산기가 됩니다.
키보드(Enter = 계산, Esc = 초기화)는 어떤 레벨에서도 정상 동작하므로 계산이 막히지 않습니다.

## 예외 처리

0으로 나누기, `log(0)`·음수 로그, 음수 제곱근, 괄호 불일치, 미지의 함수명, ζ(1) 발산,
π(x) 상한 초과 등은 모두 한국어 메시지로 안내합니다.
